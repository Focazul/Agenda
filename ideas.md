# Brainstorming de Design - Rastreador de Progresso Semanal

## Contexto
Rastreador de progresso semanal para psicólogo recém-formado, com identidade visual inspirada em lápis-lazúli (azul profundo, minimalista, introspectivo, sofisticado). O objetivo é criar uma ferramenta motivadora que combine funcionalidade com estética profunda.

---

## Resposta 1: Minimalismo Contemplativo com Ênfase em Espaço Negativo

**Design Movement:** Minimalismo Zen + Wabi-sabi (beleza na imperfeição)

**Core Principles:**
- Espaço negativo como elemento ativo (não apenas vazio)
- Tipografia grande e respirada
- Transições suaves e pausadas
- Foco na clareza sem ornamentação

**Color Philosophy:**
- Azul profundo (#1E3A6D) como cor primária (contemplação, profundidade)
- Bege (#F5F1E8) como fundo (calma, acolhimento)
- Dourado (#C8A75B) apenas para destaque de progresso (celebração sutil)
- Tons neutros para reduzir poluição visual

**Layout Paradigm:**
- Checklist centralizado com muito espaço em branco
- Barra de progresso vertical (não horizontal) para criar sensação de ascensão
- Cards de tarefas com separação generosa
- Tipografia hierárquica clara

**Signature Elements:**
- Linha vertical animada que "cresce" conforme o progresso
- Ícones minimalistas e geométricos
- Transições fade-in suaves

**Interaction Philosophy:**
- Cliques satisfatórios mas discretos (sem explosões de confete)
- Feedback visual sutil (mudança de cor, pequena animação)
- Sensação de "meditação produtiva"

**Animation:**
- Transições de 300-500ms (não muito rápidas)
- Easing: ease-in-out para suavidade
- Animações de entrada: fade + slide leve

**Typography System:**
- Display: Playfair Display (elegância, sofisticação)
- Body: Lato (legibilidade, modernidade)
- Hierarchy: 3.5rem → 2rem → 1.25rem → 1rem

**Probability:** 0.08

## Resposta 2: Dashboard Analítico com Visualização de Dados

**Design Movement:** Data Visualization Moderna + Neomorphism

**Core Principles:**
- Dados como narrativa visual
- Gráficos e métricas em primeiro plano
- Interatividade exploratória
- Feedback quantitativo claro

**Color Philosophy:**
- Azul médio (#2F5DA8) como cor de dados
- Gradientes azul-escuro → azul-médio para profundidade
- Dourado (#C8A75B) para destaque de metas atingidas
- Cinza suave para contexto

**Layout Paradigm:**
- Grid assimétrico com gráficos de pizza, barras e linhas
- Seção lateral com estatísticas semanais
- Histórico visual de progresso (últimas 4 semanas)
- Cards com sombras suaves (neomorphism)

**Signature Elements:**
- Gráfico de progresso circular (0-100%)
- Mini-gráficos de tendência por tarefa
- Badges/medalhas para semanas completas

**Interaction Philosophy:**
- Hover revela mais detalhes
- Cliques exploram histórico
- Sensação de "controle e domínio"

**Animation:**
- Números contadores animados
- Gráficos que "desenham" ao carregar
- Transições de página suaves

**Typography System:**
- Display: Montserrat Bold (confiança, clareza)
- Body: Roboto (neutralidade, legibilidade)
- Hierarchy: 2.5rem → 1.75rem → 1.25rem → 1rem

**Probability:** 0.07

## Resposta 3: Jornada Introspectiva com Elementos Orgânicos

**Design Movement:** Organic Modernism + Psicologia Visual

**Core Principles:**
- Formas curvilíneas e fluidas (não retas)
- Narrativa emocional do progresso
- Texturas sutis e padrões naturais
- Crescimento como metáfora visual

**Color Philosophy:**
- Azul escuro (#0F1C2E) como base (profundidade psicológica)
- Gradientes suaves entre azuis
- Dourado (#C8A75B) como "luz interior" revelada
- Bege (#F5F1E8) como espaço de respiro

**Layout Paradigm:**
- Checklist em forma de "árvore de crescimento" (vertical, ramificada)
- Formas orgânicas (blob shapes) para cards
- Fundo com padrão sutil (linhas onduladas, pontos)
- Progresso visualizado como "floração" de elementos

**Signature Elements:**
- Ícones com traços orgânicos
- Formas blob para cards de tarefas
- Padrão de fundo dinâmico (ondas, pontos)
- Animação de "floração" ao completar tarefas

**Interaction Philosophy:**
- Cliques revelam "pétalas" de progresso
- Sensação de cultivo e crescimento pessoal
- Feedback emocional (celebração genuína)

**Animation:**
- Morphing de formas (blob → expandido)
- Partículas flutuantes ao completar
- Transições fluidas e orgânicas

**Typography System:**
- Display: Poppins SemiBold (moderno, acessível)
- Body: Inter (clareza, profissionalismo)
- Hierarchy: 3rem → 2rem → 1.5rem → 1rem

**Probability:** 0.09

---

## Decisão Final

**Abordagem Escolhida: Minimalismo Contemplativo com Ênfase em Espaço Negativo**

Esta abordagem foi selecionada porque:
1. Alinha-se perfeitamente com a identidade visual lápis-lazúli (profundo, introspectivo, sofisticado)
2. Reduz a poluição visual, permitindo que o usuário se concentre nas tarefas
3. A barra de progresso vertical cria uma metáfora visual de "ascensão" que é psicologicamente motivadora
4. A tipografia respirada e o espaço negativo refletem a filosofia de "consistência sem sobrecarga"
5. As transições suaves e discretas evitam estimulação excessiva, mantendo a calma
6. É escalável para futuras adições (horários, sub-tarefas) sem perder elegância

**Diretrizes Visuais Finais:**
- Fundo: Bege (#F5F1E8)
- Primária: Azul Profundo (#1E3A6D)
- Destaque: Dourado (#C8A75B)
- Tipografia: Playfair Display + Lato
- Espaçamento: Generoso, respirado
- Animações: Suaves, 300-500ms, ease-in-out
